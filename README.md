# App Expresso

Esqueleto inicial de um aplicativo Android nativo em Kotlin. Este repositório contém apenas a estrutura de partida; funcionalidades, identidade visual e integrações ainda precisam ser definidas.

## Requisitos

- JDK 17 ou superior
- Android SDK instalado (compile/target SDK 35)
- Android Studio recente, que pode sincronizar e baixar a versão necessária do Gradle e os plugins

## Abrir

Abra esta pasta no Android Studio e aguarde a sincronização do Gradle. Depois, execute a configuração `app` em um emulador ou dispositivo conectado.

## Estrutura

```text
app/
  src/main/
    java/br/com/dmexpresso/appexpresso/MainActivity.kt
    AndroidManifest.xml
build.gradle.kts
settings.gradle.kts
gradle.properties
```

> Este scaffold ainda não foi compilado e não inclui APK nem Gradle Wrapper. Nenhuma funcionalidade específica do produto foi implementada.
